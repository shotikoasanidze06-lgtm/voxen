# Voxen

Fast Minecraft Java launcher with FPS boost and mods, plus free server hosting from your own PC.

- Website: https://shotikoasanidze06-lgtm.github.io/voxen/
- Download: [VoxenSetup.exe](https://github.com/shotikoasanidze06-lgtm/voxen/releases/latest/download/VoxenSetup.exe)
- Relay (lets anyone join a Voxen server by name): [relay/](relay/), one-command setup in `relay/setup_relay.sh`

Voxen is not affiliated with Mojang Studios or Microsoft.
